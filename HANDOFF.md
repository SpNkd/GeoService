# GeoService — release candidate hardening, 2026-10-08

Ветка `codex/real-world-product-hardening` создана от очищенного публичного `main` **b53b26c**. Этот проход не публиковался: GitHub/GitVerse Pages остаются на прежней сборке из 2be40f3. Старую приватную историю не merge/cherry-pick без отдельного аудита; не использовать `push --all/--mirror`. Текущая задача запрещает push/deploy. Разрешение встроенной публикации Pages из предыдущей задачи не является разрешением публикации этих изменений.

Результат: **READY FOR BROADER MANUAL TESTING**, открытых P0/P1 по выполненной матрице не выявлено. Новые подсистемы не добавлялись. Исправлены четыре воспроизведённых дефекта:

- P1: pagehide autosave оставлял «Сохранение…» после успеха/ошибки. Debounce и flush используют общий revision-guarded обработчик завершения; quota сохраняет предыдущую запись, повторная запись восстанавливается. Завершение асинхронной записи при принудительном уничтожении процесса браузера не гарантируется.
- P1: REAL запросы с «трёх метров» отвергались numeric provenance. Добавлена ограниченная грамматика русских числительных 0–99; это не phrase matching действий и не разрешение придуманных XY.
- P2: повторный stationary click выбранного ATTRIB сбрасывал индекс overlap-cycle. Tab/Shift+Tab теперь продолжают от фактического выбранного кандидата.
- P2: вкладки Properties/Search/AI получили связанные `tabpanel`, `aria-controls` и подписи; панели остаются mounted, черновики сохраняются.

Проверки: unit **1216 passed / 95 skipped**, полный Chrome E2E **281 passed / 18 skipped**, REAL UI **1 passed**; typecheck/lint/build PASS, официальный npm audit **0 vulnerabilities**. Восемь различных private reference сценариев PASS с выборочными повторениями. REAL corpus: 13 разных случаев PASS после двух исправленных/повторённых отказов, 15 наблюдённых upstream попыток. Всего в задаче 21 логический REAL запрос, включая DEV UI и публичные connection/plan checks; число upstream попыток двух DEV UI вызовов отдельно не инструментировалось.

Production — только статические файлы. Browser AI обращается прямо к OpenRouter с ключом посетителя; DEV сохраняет локальный API adapter. Prompt/schema, validation и local resolution общие. Ключ по умолчанию в памяти, Remember явно сохраняет отдельную localStorage запись. Без ключа редактор работает. Провайдер получает введённый текст/структурированный ответ и фиксированную схему, без автоматической передачи документа/файлов/изображений/семантических правил. REAL acceptance использовал `qwen/qwen3.5-27b`, без дорогого model upgrade или mock fallback. Игнорируемый `.env.local` не изменялся и не входит в сборку.

DEV **http://127.0.0.1:5173/** оставлен работающим. Production-style preview **http://127.0.0.1:5180/GeoService/** также работает. `npm run build` и `npm run preview:static` проверяют относительный base path без API. Local static smoke: 13/13 PASS; неизменённые GitHub/GitVerse Pages: 14/14 PASS на каждой площадке, включая REAL AI, PDF/OCR/Workers. GitVerse `ERR_BLOCKED_BY_CLIENT` обычного профиля остаётся внешним ограничением; изолированный Chrome проходит, настройки безопасности не менялись.
