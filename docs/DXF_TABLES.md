# Локальные таблицы DXF

Поиск → Tables распознаёт ортогональную сетку и текст в Model, Paper Space и определениях блоков. Результат доступен только для чтения; это локальное представление исходных примитивов, без изменения документа.

Для размещённых экземпляров доступны выбор и Fit. Определение без экземпляра помечается явно: MODEL Fit недоступен; отдельный preview использует координаты определения. Положение таблицы не придумывается.

Распознавание ограничено бюджетами строк, ячеек и примитивов. Объединённые ячейки не всегда восстанавливаются из exploded geometry. Кандидат не становится самостоятельной редактируемой таблицей. Текст, геометрия и исходные handles не отправляются AI.

См. [Поиск и свойства](SELECTION_PROPERTIES.md), [DXF](DXF_IMPORT.md).
