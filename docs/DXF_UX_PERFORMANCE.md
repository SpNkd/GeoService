# DXF: взаимодействие и производительность

Импорт сохраняет канонических владельцев и общие определения блоков. Основная геометрия рисуется Canvas; selection, hover и инструменты используют отдельные лёгкие overlays. Геометрический BVH и локальные derived indexes ускоряют hit testing и поиск; изменение стиля/видимости не требует повторного извлечения семантического текста.

Длинные списки слоёв и source metadata ограничены/виртуализированы. Paper Space и поддерживаемые MODEL viewports используют независимую навигацию, clipping и VP Freeze. Global visibility сохраняется отдельно.

Публичные fixtures синтетические. Исходные reference-отчёты исключены из открытой истории: они содержали данные частного чертежа. Наличие локальной reference acceptance не является обещанием производительности для произвольного DXF.
